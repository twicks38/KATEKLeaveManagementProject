Git Commands/Standard Practice:

git checkout - Moving between branches
git pull 
git add . / git add *filename*

No changes should be pushed directly to main.
Changes should first be pushed to a branch where a Pull Request (PR) can be raised for review before merged into main.

When making commits/pushing:

When making commits, always choose commit and push if pushing through the VSCode GUI
Ensure that files you want to commit/push have been selected to be Staged with the Plus
